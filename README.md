
# Elevate Labs – SQL Developer Internship

## 📌 About the Internship

This repository contains my daily tasks, SQL queries, practice exercises, and learning outcomes completed during my **SQL Developer Internship at Elevate Labs**.

The internship focuses on developing practical SQL and database skills through hands-on tasks and real-world problem-solving.

Day 01 – Database & Table Creation

Objective:

To learn how to create a database, design and create tables, define columns with appropriate data types, and establish relationships between tables using Primary Keys and Foreign Keys.

Day 02 – Data Insertion and Handling NULLs

Objective:

To practice inserting data into tables using INSERT INTO, handling missing values using NULL, updating existing records using UPDATE, and removing records using DELETE statements.

Day 03 – Writing Basic SELECT Queries

Objective:

To learn how to retrieve data from one or more tables using SELECT statements, filter records using WHERE conditions, and organize results using ORDER BY and LIMIT.
